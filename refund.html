退款与返款政策

最后更新: 2026年4月

1. 政策概览

本退款与返款政策规定了 Everland Technology Limited（以下简称"公司"）关于服务退款、返款和退还的条款和条件。我们致力于为客户提供优质的服务，并公平对待所有退款请求。

2. 适用范围

本政策适用于：

  1. 通过公司获得的App开发服务
  2. 信息咨询服务
  3. 技术支持和维护合同
  4. 所有其他公司提供的服务

3. 退款资格

3.1 可退款服务

以下情况下，客户可能有资格获得全部或部分退款：

  1. 由于公司的错误或过失，服务未按照约定交付
  2. 交付的工作成果明显不符合既定的质量标准
  3. 公司未能在合理的时间内完成项目
  4. 在项目开始后的30天内，客户决定取消合同（新项目）
  5. 由于公司技术障碍，导致服务不可用

3.2 不可退款的情况

以下情况下，客户不符合退款资格：

  1. 由于客户改变主意而取消项目（超过30天的取消期后）
  2. 服务交付后60天以上的退款请求
  3. 客户未能及时提供必要信息或反馈，导致项目延迟
  4. 由于客户的不合理要求，项目范围不断扩大
  5. 客户违反本协议或服务条款
  6. 客户已获得或使用了完整的服务或工作成果

4. 退款流程

4.1 提交退款请求

要请求退款，客户必须：

  1. 向公司发送书面退款请求（电子邮件至 admin@everlandapps.com）
  2. 详细说明退款原因和相关信息
  3. 提供必要的文件和证据支持请求
  4. 确保请求在服务交付后60天内提交

4.2 审核过程

公司将在收到退款请求后按照以下步骤处理：

  1. 在5个工作日内确认收到请求
  2. 对请求进行调查和评估（7-14个工作日）
  3. 与客户沟通任何需要的额外信息
  4. 作出退款决定并通知客户

4.3 退款决定时间

公司承诺在收到完整退款请求后14个工作日内做出决定。在复杂情况下，可能需要额外的时间。

5. 部分退款与折扣

5.1 部分完成的工作

如果客户在项目部分完成时取消，退款将按照以下方式计算：

  1. 已完成工作的费用将不予退款
  2. 未开始的工作费用将全额退款
  3. 部分完成的工作费用将按比例计算

5.2 已产生的费用

客户应负责支付所有已产生的实际成本，包括但不限于：

  1. 已使用的软件许可证费用
  2. 第三方工具和服务的费用
  3. 云服务和托管费用
  4. 外包工作和合作伙伴的成本

5.3 折扣选项

在某些情况下，客户可能不符合完全退款的条件，但可能有资格获得以下之一：

  1. 部分退款（10%-50%）
  2. 服务折扣（应用于未来项目）
  3. 免费咨询时间

6. 退款方式

6.1 原付款方式返还

批准的退款将通过原始付款方式返还给客户。例如：

  1. 银行转账：退款至原始银行账户
  2. 信用卡：退款至原始信用卡
  3. 其他方式：按原始付款方式处理

6.2 退款处理时间

退款决定后，资金通常需要5-10个工作日才能返还到您的账户。具体时间可能因您的金融机构而异。

7. 特殊服务条款

7.1 定制App开发

对于定制App开发项目：

  1. 项目开始后30天内，客户可以无条件取消并获得100%退款
  2. 30-60天内，可以请求50%的退款（扣除已产生费用）
  3. 超过60天，不符合退款资格，除非服务存在重大缺陷

7.2 咨询服务

对于信息咨询服务：

  1. 咨询后7天内，客户可以要求退款
  2. 退款将扣除已提供的实际咨询时间（按小时计算）
  3. 如果咨询已完全交付，不符合退款资格

7.3 维护合同

对于年度或按月的维护合同：

  1. 客户可以在计费周期结束前30天通知以取消
  2. 提前取消可能涉及最少3个月的费用（取决于合同条款）
  3. 不提供按比例退款

8. 争议解决

8.1 退款争议

如客户对退款决定提出异议，可以：

  1. 在10个工作日内向公司管理层提出申诉
  2. 要求进行独立审查
  3. 提供额外的证据或信息支持申诉

8.2 调解

如无法通过协商解决，双方可以同意进行调解或仲裁。

9. 非退款替代方案

9.1 重做或调整

在某些情况下，我们可能会提供重做或调整服务，而不是退款。这包括：

  1. 更正不符合质量标准的工作
  2. 添加之前遗漏的功能
  3. 进行性能优化

9.2 延期或转移

客户也可以选择：

  1. 将服务推迟到未来日期
  2. 将付款转移到其他项目或服务

10. 政策变更

公司保留随时修改本退款政策的权利。任何重大变更将提前30天通知。继续使用我们的服务表示接受更新的政策。
