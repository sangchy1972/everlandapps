# 💻 Everland Technology 网站 - 快速命令参考

## 🔧 GitHub 推送命令
复制这些命令到你的终端（替换 YOUR_USERNAME 为你的 GitHub 用户名）

=== 第 1 次设置 ===
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/everland-website.git
git push -u origin main

=== 以后更新网站 ===
git add .
git commit -m "更新网站内容"
git push origin main

## 🌐 Vercel 部署
1. 访问 https://vercel.com
2. 登录或注册（用 GitHub 账号）
3. 点击 "New Project"
4. 选择 "everland-website" 仓库
5. 点击 "Deploy"
6. 等待完成

---

## 📍 Cloudflare DNS 配置
在 https://dash.cloudflare.com

登录 → 选择 everlandapps.com → DNS

添加两条 CNAME 记录：

记录 1：
类型: CNAME
名称: @ (或 everlandapps.com)
内容: cname.vercel-dns.com
TTL: 自动
代理: 仅 DNS
保存

记录 2：
类型: CNAME
名称: www
内容: cname.vercel-dns.com
TTL: 自动
代理: 仅 DNS
保存

## ✅ 验证 DNS
打开终端运行：

应该看到类似的输出：

## 🆘 遇到问题？

DNS 未验证？
→ 检查 Cloudflare 中的 CNAME 记录是否正确
→ 等待 DNS 传播（通常 5-30 分钟）
→ 在 Vercel 重新尝试验证

网站无法加载？
→ 确认 Vercel 部署状态是 "Ready"
→ 刷新页面（Ctrl+Shift+R 强制刷新）
→ 检查浏览器控制台是否有错误

Git 推送失败？
→ 确认用了 HTTPS URL，不是 SSH
→ 检查是否用了正确的 GitHub token
→ 确认仓库权限设置为 Public
